# Dirección visual (decidida por el usuario)

- **Fondo blanco**, diseño **elegante, claro y sin complicaciones**.
- Móvil primero (PWA con cámara para subir tickets).
- El usuario subirá una **captura de referencia** del estilo que quiere si hace falta. **Pendiente: esperar esa captura antes de diseñar la web (hito H1).**
- Las skills `ui-ux-pro-max` y `frontend-design` no están disponibles en esta sesión; no se instala nada sin permiso explícito.

Criterios iniciales (a confirmar con la captura): mucho espacio en blanco, tipografía legible, un único color de acento sobrio, jerarquía clara, semáforo de plazos (rojo/ámbar/verde) con contraste accesible (WCAG AA), formularios cortos, un CTA principal por pantalla.
